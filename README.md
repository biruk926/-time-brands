# TIME BRAND

Premium watch e-commerce store with a real backend, Vercel Blob storage, and an admin dashboard.

## Architecture

- Frontend: HTML, CSS, Vanilla JS
- Backend: Flask serverless function at `api/index.py`
- Storage: Vercel Blob (products.json, orders.json, users.json, messages.json)
- Deployment: Vercel
