# TIME BRAND

Premium footwear ecommerce with manual Telebirr/CBE payment verification.

## Environment Variables

- BLOB_READ_WRITE_TOKEN: Vercel Blob token
- ADMIN_PASSWORD: Admin login password (default: time)
- SECRET_KEY: Flask session secret

## Payment Accounts

- Telebirr: 0940213338
- CBE: 1000641150324

## Deployment

1. Push to GitHub
2. Import to Vercel
3. Set environment variables
4. Deploy

## Admin Login

- URL: /admin.html
- Password: time (or your ADMIN_PASSWORD)
